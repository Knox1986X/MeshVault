# MeshVault (Android)

Локальный менеджер паролей (аналог Bitwarden) и зашифрованная галерея с полноэкранным просмотрщиком на Kotlin + Jetpack Compose (Material 3).

## Возможности
- **Криптография**: AES-256-GCM для базы данных (`vault.enc`) и каждого медиафайла/миниатюры; вывод ключа из мастер-пароля через `PBKDF2WithHmacSHA256` (600 000 итераций); защита экрана `FLAG_SECURE`.
- **Менеджер паролей**: логины, банковские карты, защищённые заметки, встроенный TOTP-аутентификатор (RFC 6238) с таймером, поиск, фильтры, избранное.
- **Генератор**: криптостойкие пароли и парольные фразы с оценкой энтропии.
- **Зашифрованная галерея**: импорт фото и видео через системный Media Picker, зашифрованные миниатюры, мультивыбор, фильтры.
- **Просмотрщик**: `HorizontalPager` (свайпы), pinch-to-zoom и двойной тап для фото, встроенный видеоплеер на базе Media3 ExoPlayer, метаданные.
- **Безопасность**: биометрия (`BiometricPrompt`) и настраиваемая автоблокировка при уходе в фон.

## Сборка
Откройте проект в Android Studio (Ladybug / Meerkat+) с JDK 17 и Android SDK 35, выполните Sync Gradle и запустите на устройстве или эмуляторе (`minSdk = 26`).
